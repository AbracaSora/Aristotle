## 浏览器操作

使用本地 `/demo` 实际完成：

1. 登录 student1，读取三知识点的初始证据不足状态。
2. 请求三道线性基础题，逐题选择并提交；1—2 题正确时仍为证据不足，第三题保存后转为初步掌握。
3. 再次请求任务，推荐自动变为“栈的概念 / understand”，而不是固定返回原关卡。
4. 切换 editor，创建 `team_example_1:v1`；界面依次显示 draft、pending_review、published，候选来源明确为手动录入。

上述操作使用本地演示库。该库额外保留一条浏览器核验新增的自编样例、三条 student1 作答和任务记录，便于继续查看；不提交 Git，也不打入交付源代码包。重新初始化命令不会覆盖它。

## 覆盖范围与局限

本次验证是后端设计原型的功能检查，不等于 AC-01—09 完整验收。AC-01 缺完整范围选择及前端联调，AC-02 缺 PDF，AC-03 缺真实 LLM，AC-04 的回退策略仍需细化，AC-06 无真实模型失败注入，AC-08 无学生报错入口。其他场景也只覆盖原型已有路径，不能整体标记通过。
