## 2. 关键业务顺序

发布配置 → 校验知识图/题目/预设版本 → 学生查看课程 → 校验全部直接先修的预设完成 → 创建或恢复预设任务 → 按固定版本提交 → 聚合题目完成与正确率 → 重新计算后继解锁 → 预设全完成后创建最终小测 → 冻结题目与规则 → 整卷确定性评分 → 通过才 mastered → 返回稳定事件和规则建议 → 可选模型补充反馈。

旧的初始诊断和规则推荐继续提供另一种学习入口。两套策略有不同含义和版本：`baseline-0.1` 的练习证据判断，不是 `mastery-v1` 的预设覆盖/最终小测状态。不能把“答对率达到80%”移植成新课程解锁条件。
